# SC-CHANGES-WORKSPACE: Изменения

Экран помогает проверить текущий Git diff и продолжить обсуждение любого
изменённого файла, не покидая локальный портал. Новые сообщения агенту
разрешены для обычных файлов сравнения с рабочим деревом. Публичный `ChangeSetReport` по-прежнему
ограничен документацией.

Актуальный снимок экрана пока не подготовлен. Файл
`assets/screens/changes-workspace.png` показывает прежнюю компоновку и поэтому
не указан как превью этого документа.

## Что видит пользователь

В верхней панели находятся переходы в портал, редактор и раздел «Изменения»,
кнопка «Обсуждения · N», а также выбор темы и цветовой схемы. Счётчик охватывает
все открытые ветки проекта. Ниже показаны диапазон Git и число изменённых файлов
и строк.

Параметры диапазона скрыты под раскрывающейся строкой. Там можно задать
начальное и конечное состояния и, при необходимости, базовую ветку. Рядом
показано, во что разрешились ссылки Git, какая ветка открыта и есть ли локальные
правки. Панель закрывается после применения, по `Esc` или клику снаружи и
возвращает фокус на строку диапазона.

## Список файлов

Файлы отсортированы по пути и разделены на две группы:

- «Изменённые» — файлы из текущего Git diff;
- «Связанные» — файлы, которые пользователь добавил для контекста обсуждения.

В панели есть поиск, отбор по состоянию и области, а также фильтр «Тип»: все
файлы, только документация вместе с корневым `CHANGELOG.md` или только остальные
файлы репозитория. Связанный файл сохраняется в локальном состоянии только после
первого комментария.

Первый подходящий файл открывается автоматически. После обновления страницы
Toudocu старается сохранить выбранные файл, вкладку и фильтры. Если ничего не
подходит, экран честно сообщает, что список пуст.

После выбора файла список и URL обновляются сразу. Пока Toudocu загружает
подробные данные только этого файла, основная область показывает его заголовок
и сообщение «Загрузка файла…». Для Markdown тот же ответ содержит безопасно
отрисованные версии «До» и «После». Повторное переключение вкладок использует
уже полученные данные и не запускает тот же запрос заново. Если пользователь
успел выбрать другой файл, запоздавший ответ не меняет открытую область. После
ошибки файл можно выбрать повторно.

## Просмотр файла

Основная вкладка называется «Diff» и показывает точный патч Git. Внутри неё
можно выбрать единый вид или две стороны и скопировать патч. Отдельной вкладки
«Сводка» нет; старые ссылки с `tab=summary` и `tab=source` перенаправляются на
«Diff». В режиме двух сторон строки не переносятся, каждая колонка прокручивается
по горизонтали, а цветом выделяются только точные удалённые и добавленные
фрагменты.

Вкладка «Файл целиком» загружает текущий UTF-8 файл только при открытии. Для
удалённого файла показывается последняя версия до удаления. Markdown, JSON,
YAML, Go, Java, JavaScript и TypeScript получают подсветку; остальные текстовые
файлы отображаются как обычный текст.

Для документации появляются только применимые вкладки: «До и после»,
«Семантика», «Связи», OpenAPI, Mermaid, ресурсы или карта экранов. Диагностические
сообщения скрыты, пока они не нужны; сообщение уровня `error` раскрывается
автоматически. В представлении «До и после» заголовок изменённого раздела
получает метку и фон, а внутри него цветом выделяются только отличающиеся между
версиями блоки. Добавленный, удалённый или перемещённый раздел выделяется
целиком на доступных сторонах сравнения.

## Комментарии и ответы агента

Сообщение можно оставить для целого файла, новой строки патча или
выделенного фрагмента во вкладке «Файл целиком» и в едином diff. Меню выделения
в обоих режимах позволяет скопировать чистый текст, скопировать контекст либо
добавить вопрос и не снимает выделение при отпускании указателя.

Новая сторона единого diff сохраняет точный диапазон файла. Для старой стороны
Toudocu создаёт привязку к файлу без диапазона
и добавляет в текст сообщения видимую цитату с путём и старым номером строки.
Смешанное выделение остаётся доступным только для копирования. Полностью
удалённый, двоичный или большой файл допускает обсуждение целиком, даже когда
просмотр содержимого завершился ошибкой. У строк с точной или файловой
привязкой знак «+» виден при наведении и фокусе, а на сенсорном экране — постоянно.

Форма позволяет выбрать вопрос или запрос изменения. `Ctrl`+`Enter` или
`Cmd`+`Enter` сохраняет сообщение и сразу добавляет его в очередь, `Esc`
отменяет ввод.

Панель обсуждений открывается поверх рабочей области справа и показывает все
ветки проекта: сначала открытые, затем закрытые. Ожидающее сообщение можно
изменить или удалить, пока агент не получил его через `agent next`.
Любую открытую или закрытую ветку можно удалить целиком после подтверждения.
Вместе с ней безвозвратно удаляются сообщения и ещё не обработанные записи
очереди этой ветки.
Полученное агентом сообщение неизменяемо; продолжить ветку можно новым сообщением после
ответа агента.

Кнопка «Скопировать промт» немедленно копирует просьбу обработать очередь и не
меняет состояние. Результат агента отображается как ответ, изменение,
отсутствие нужного изменения, запрос уточнения или ошибка и не закрывает
обсуждение автоматически.

## Обновление и размеры экрана

Toudocu отдельно следит за изменениями репозитория и обсуждений. Если открытый
файл изменился, появляется предложение обновить его. Текст незавершённого
комментария сохраняется, но место нужно выбрать снова.

На широком экране список файлов и diff расположены рядом, а панель обсуждений
занимает место справа, как Agent Console. Открытие одной из этих панелей закрывает
другую. На узком экране панель обсуждений перекрывает рабочую область, делает её
недоступной для фокуса и удерживает фокус внутри. Она закрывается явной кнопкой
или по `Esc`, но не нажатием на фон, после чего фокус возвращается на вызвавший
элемент. Анимация отключается при `prefers-reduced-motion`, а состояния и
результаты выражены текстом, а не только цветом.

## Где экран доступен

Раздел и запись обсуждений доступны только в основном портале, запущенном через
`serve`, и только при `target=working-tree`. Сравнения с индексом или ревизией
скрывают обсуждения, а сервер отклоняет запись. В статической сборке, переводном портале и
при прямом запуске каталога перевода этой возможности нет.
