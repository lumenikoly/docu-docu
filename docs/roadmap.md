# Дорожная карта

Дорожная карта показывает, что уже входит в Toudocu и какие направления
развиваются дальше. Связанный `UC-*` завершён, только когда его собственный
документ имеет статус группы `done`, хотя бы одну галочку в критериях приёмки и
все отмеченные галочки этого раздела. Галочка в дорожной карте должна совпадать
с этим результатом. Разделы с номером версии описывают релизы.

## Реализовано
- [x] `UC-DOCS-01` Пользователь собирает автономный портал документации.
- [x] `UC-DOCS-02` Пользователь проверяет структуру и связи документации.
- [x] `UC-DOCS-03` Пользователь открывает документацию на локальном сервере.
- [x] `UC-DOCS-04` Пользователь изучает карту экранов и переходы.
- [x] `UC-DOCS-05` Пользователь просматривает изменения документации.
- [x] `UC-TASK-01` Исполнитель получает контекст выбранной рабочей задачи.
- [x] `UC-TASK-02` Исполнитель явно запускает команды проверки этой задачи.
- [x] `UC-TASK-03` Исполнитель создаёт новую рабочую задачу.
- [x] `UC-TASK-04` Исполнитель архивирует или восстанавливает рабочую задачу.
- [x] `CON-CLI-V1` Публичный контракт CLI и версионированные JSON-схемы
  зафиксированы.
- [x] `DLV-INSTALL-01` Описаны установка и обновление из GitHub Release, а
  также сборка из исходников.
- [x] `DLV-SKILL-WORKFLOWS-01` Описаны действия встроенного навыка: `init`,
  `refresh` и `translate`.
- [x] `DLV-SELF-DOCS-01` Репозиторий содержит собственную документацию в
  формате Toudocu.
