# UC-TASK-04: Архивировать или восстановить рабочую задачу

Актор: исполнитель — разработчик или программный агент.

Исполнитель переносит завершённую или отменённую задачу из активного списка в
годовой архив либо возвращает её обратно. Содержимое задачи при этом не
меняется.

## Входные данные

- стабильный ID `TASK-*` или `BUG-*`;
- основной каталог документации;
- корень репозитория;
- формат ответа `text` или `json`.

<!-- toudocu:section prerequisites -->
## Предусловия

- архивируемая задача имеет статус «Выполнено» или «Отменено»;
- целевой файл ещё не существует;
- перенос не разорвёт прямые относительные ссылки Markdown.

<!-- toudocu:section main-scenario -->
## Основной сценарий

1. Исполнитель запускает `toudocu task archive TASK-ID ./docs`.
2. Toudocu находит ровно одну задачу и проверяет её статус, содержимое, исходный
   и целевой пути.
3. Утилита убеждается, что после переноса разрешение прямых Markdown-ссылок не
   изменится.
4. Файл без перезаписи перемещается в `work/archive/YYYY/`.
5. Отчёт `TaskMoveReport` получает состояние `archived`.
6. Чтобы вернуть задачу, исполнитель запускает
   `toudocu task restore TASK-ID ./docs`.
7. Тот же файл без изменения содержимого возвращается в `work/`, а отчёт
   получает состояние `restored`.

## Ошибочные сценарии

- Отсутствующий или повторяющийся ID блокирует операцию.
- Активная задача не архивируется.
- Существующий целевой путь не перезаписывается.
- Опасный путь архива, символическая ссылка или выход за корень репозитория
  отклоняется.
- Если прямая Markdown-ссылка станет вести в другое место или перестанет
  работать, файл остаётся на месте.
- Каталог перевода не принимается как рабочий контекст.

<!-- toudocu:section postconditions -->
## Постусловия

При успехе изменилось только расположение одного файла. ID, статус, зависимости,
история и весь Markdown сохранены. При отказе файловая система не меняется.

<!-- toudocu:section acceptance-criteria -->
## Критерии приёмки

- [x] Успешная операция меняет только расположение одного файла и сохраняет ID,
  статус, зависимости, историю и Markdown.
- [x] При отказе файловая система не меняется.

## Проверка сценария

Покрываются архивирование и восстановление, запрет активного статуса,
конфликт назначения, опасный путь, сохранение содержимого и блокировка ссылок,
которые после переноса разрешались бы иначе.
