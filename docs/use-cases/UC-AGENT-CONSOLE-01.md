# UC-AGENT-CONSOLE-01: Выполнить задачу с агентом в Toudocu

Актор: разработчик, открывший локальный портал на своём компьютере.

<!-- toudocu:section main-scenario -->
## Основной сценарий

1. Разработчик открывает готовую задачу и нажимает значок Agent Console рядом с
   действием «Начать работу».
2. Toudocu собирает актуальные сведения о задаче и запускает выбранный Codex
   или OpenCode с указанным режимом доступа.
3. Вкладка Agent View показывает разговор, а Command Output — выполняемые
   команды и их результаты.
4. Разработчик может дополнить поручение, подтвердить запрошенное действие или
   остановить текущий ответ.
5. Готовые действия позволяют уточнить требования, продолжить работу, обновить
   документацию по изменениям и обработать запросы из обсуждений.
6. Разработчик переходит между задачами, документацией, изменениями и
   редактором, не завершая сессию.
7. После работы он выбирает «Остановить агента».

Для родительской задачи разработчик может выбрать `Complete task tree`.
Toudocu проверяет дерево и последовательно передаёт одному агенту готовые
подзадачи. Родительская задача выполняется после дочерних; интерфейс показывает
текущую задачу и общий прогресс. Запрос подтверждения приостанавливает работу,
а остановка, ошибка или отсутствие прогресса блокируют продолжение.

Вместо запуска Agent Console разработчик может скопировать у любого доступного
действия готовое поручение и передать его внешнему агенту. Установленный навык
сам получит актуальные сведения из репозитория.

## Дополнительные пути

- Вопросы, не требующие изменений, запускаются с доступом к файлам только для
  чтения. Внешние сервисы могут иметь собственные правила доступа.
- Пользователь может открыть терминал проекта и работать в нём независимо от
  Agent Console.
- Если встроенный агент не запускается, интерфейс предлагает открыть терминал.
- Если агент не принимает уточнения во время ответа, новое сообщение ждёт
  завершения текущего ответа.
- «Спросить» создаёт разовый разговор в Agent Console.

<!-- toudocu:section postconditions -->
## Постусловия

Состояние задачи, результаты verification, Changes и Agent Feedback остаются в
своих источниках Toudocu. Agent Session завершена явно или продолжает работать
при навигации.

<!-- toudocu:section acceptance-criteria -->
## Критерии приёмки

- [ ] Готовая задача запускает одну сессию без ручного переноса сведений.
- [ ] В одной сессии можно продолжать разговор, останавливать ответ,
  подтверждать действия, проверять результат и обрабатывать запросы из
  обсуждений.
- [ ] Вкладка Command Output показывает команды и их результаты, но не
  принимает ввод.
- [ ] Опубликованный портал, перевод и портал, открытый для сети, не запускают
  агента.
- [ ] Готовое дерево задач выполняется последовательно и явно показывает
  завершение или причину остановки.
