# Toudocu

Toudocu помогает держать проектную документацию рядом с кодом и не терять
связи между требованиями, задачами и проверками. Это консольная программа на
Go: она проверяет Markdown-файлы и собирает из них удобный HTML-портал. Портал
можно разместить на любом статическом HTTP(S)-хостинге — запущенный Toudocu ему
не нужен. Возможности программы также доступны из Go-кода.

## Проблема

Документация быстро устаревает, когда статусы, связи, критерии приёмки и команды
проверки разбросаны по разным файлам и обновляются вручную.

## Решение

Toudocu связывает Markdown-файлы в цельное описание проекта и находит
расхождения в идентификаторах, ссылках, правилах, дорожной карте и рабочих
задачах. Люди читают документацию в HTML-портале, а инструменты получают те же
данные в JSON-отчёте `ProjectReport` версии 1.

## С чего начать

Выберите режим по задаче:

| Что нужно сделать | Используйте | Что получите |
|---|---|---|
| Проверить документацию в CI или перед коммитом | `toudocu check ./docs` | Список ошибок и предупреждений без изменения файлов |
| Опубликовать документацию | `toudocu build ./docs` | Автономный статический портал для обычного HTTP-хостинга |
| Читать и править документацию локально | `toudocu serve ./docs` | Портал с редактором, Git-изменениями и обсуждениями |
| Подготовить или выполнить рабочую задачу | `toudocu task ...` | Проверяемый контекст, зависимости и команды проверки |
| Актуализировать, перевести или создать документацию с агентом | `$toudocu ...` | Управляемый процесс встроенного навыка, а не команда Go CLI |

Полный список реализованных функций и ссылки на инструкции собраны в
[каталоге возможностей](reference/features.md).

## Основные возможности

Toudocu делает документацию рядом с кодом связной и проверяемой.

- **Единый портал проекта.** Поиск, навигация, архитектурная карта,
  пользовательские сценарии и текущее состояние работы собраны в одном
  понятном интерфейсе.
- **Проверяемая структура.** Toudocu находит битые ссылки, повторяющиеся
  идентификаторы, ошибки в структуре и неверно объявленные связи.
- **Понятный путь от замысла до результата.** Пользовательский сценарий и экран
  можно связать с задачей, критерием приёмки и командой проверки.
- **Осмысленный просмотр изменений.** Локальная рабочая область показывает
  точный Git diff, вид страниц до и после изменения и различия между
  документированными сущностями.
- **Локальные обсуждения документации.** В основном портале `serve` можно
  привязать вопрос или запрос изменения ко всему каноническому
  Markdown-документу или выбранному диапазону. Toudocu сохраняет ветку и
  очередь вне репозитория, но не запускает AI-агента; сообщения передаются ему
  только по явной просьбе пользователя.
- **Контекст задачи для AI-агента.** Агент получает только нужные для выбранной
  задачи требования, правила, экраны, зависимости и проверки — без права
  что-либо запустить.
- **Встроенный навык для работы с документацией.** Автономный пакет помогает
  Codex, Claude Code и Copilot создавать, уточнять, обновлять и переводить
  документацию по правилам Toudocu. CLI управляет локальной копией навыка и не
  перезаписывает изменения пользователя. Начните с
  [руководства по установке](guides/skill-installation.md), затем используйте
  [руководство по работе с AI-агентом](guides/agent-workflows.md).
- **Проверяемые рабочие задачи.** Рабочая задача объединяет разрешённую область
  изменений, критерии приёмки и команды проверки. Toudocu проверяет её готовность, выполняет явно
  разрешённые команды и сохраняет результат. В портале задачи доступны как
  доска, список и дерево с вычисленным состоянием готовности и прогрессом
  дочерних задач.
- **Локальная работа с агентом.** В локальном портале готовую задачу можно
  передать установленному Codex или OpenCode. Боковая панель показывает ответ
  и выполняемые команды, позволяет дополнить или остановить работу и не
  закрывается при переходе на другую страницу. Ту же задачу можно передать
  другому агенту готовым текстом или выполнить через обычный терминал.
- **Простая публикация.** Один исполняемый файл создаёт готовый портал без CDN,
  базы данных и npm. Локально его открывает `serve`, а опубликованную версию
  раздаёт обычный статический хостинг.

## Целевая аудитория

- разработчики и технические руководители;
- команды, ведущие документацию рядом с кодом;
- AI-агенты, которым нужен ограниченный и машиночитаемый контекст;
- CI-системы, проверяющие документационный контракт;
- Go-разработчики, встраивающие Toudocu из исходного модуля.

## Ограничения

- документация использует CommonMark с таблицами,
  чек-листами, зачёркиванием и автоматическими ссылками;
- команды `task verify --run` считаются доверенным кодом репозитория;
- результат `build` является статическим и не редактирует исходные документы;
- режим `serve` изменяет через Editor API только явно выбранные файлы основного
  каталога документации и не записывает файлы в каталогах переводов;
- глобальный прогресс определяется только `roadmap.md`.
