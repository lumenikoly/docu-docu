# Установка и обновление Toudocu

Установщики GitHub Release — основной способ установить или обновить Toudocu.
Сборка из исходников остаётся доступной для разработки и проверки изменений.

## Установить или обновить последний стабильный выпуск

Linux и macOS:

```sh
curl -fsSL https://github.com/lumenikoly/toudocu/releases/latest/download/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://github.com/lumenikoly/toudocu/releases/latest/download/install.ps1 | iex
```

Повторный запуск не заменит бинарник, если его SHA-256 уже
совпадает с файлом из релиза. При новой версии установщик заменит прежний файл
только после успешной загрузки, проверки контрольной суммы и сверки версии.

Проверьте, что установленный бинарник доступен из `PATH`:

```bash
toudocu version
```

## Поддерживаемые платформы

| Система | Архитектура | Файл релиза |
|---|---|---|
| Linux | AMD64 / x86-64 | `toudocu-linux-amd64` |
| Linux | ARM64 / AArch64 | `toudocu-linux-arm64` |
| macOS | Intel | `toudocu-darwin-amd64` |
| macOS | Apple silicon | `toudocu-darwin-arm64` |
| Windows | AMD64 / x86-64 | `toudocu-windows-amd64.exe` |
| Windows | ARM64 | `toudocu-windows-arm64.exe` |

На Windows ARM64 установщик выбирает нативный ARM64-бинарник, в том числе при
запуске из x64-процесса под эмуляцией. Другие неперечисленные комбинации
завершаются ошибкой до загрузки.

## Выбрать версию

В POSIX-оболочке выбранная версия передаётся процессу после конвейера:

```sh
curl -fsSL https://github.com/lumenikoly/toudocu/releases/latest/download/install.sh \
  | TOUDOCU_VERSION=0.0.7 sh
```

PowerShell получает ту же переменную:

```powershell
$env:TOUDOCU_VERSION = "0.0.7"
irm https://github.com/lumenikoly/toudocu/releases/latest/download/install.ps1 | iex
Remove-Item Env:TOUDOCU_VERSION
```

Допускаются форматы `X.Y.Z` и `X.Y.Z-rc.N` без префикса `v`. Явная версия
позволяет закрепить выпуск, намеренно вернуться к предыдущему или установить
явно выбранный кандидат. `latest` всегда выбирает стабильный выпуск.

## Каталог и PATH

По умолчанию бинарник устанавливается в:

- `~/.local/bin/toudocu` на Linux и macOS;
- `%LOCALAPPDATA%\Programs\toudocu\toudocu.exe` на Windows.

Если этого каталога нет в `PATH`, установщик добавляет одну управляемую запись в
`.bashrc`, `.zshrc`, fish `conf.d`, `.profile` или пользовательский `PATH`
Windows. Он не может изменить уже запущенную оболочку, поэтому печатает точную
команду
`source`, просит войти в систему заново или открыть новое окно терминала
Windows.

Другой каталог не меняет профиль оболочки:

```sh
curl -fsSL https://github.com/lumenikoly/toudocu/releases/latest/download/install.sh \
  | TOUDOCU_INSTALL_DIR="$HOME/bin" sh
```

`TOUDOCU_NO_MODIFY_PATH=1` отключает изменение профиля или пользовательского
`PATH` Windows. В обоих случаях установщик печатает каталог, который нужно
добавить в `PATH` вручную.

## Граница доверия

Начальный установщик по HTTPS скачивает бинарник и `checksums.txt` из одного
GitHub Release. Он требует ровно одну запись SHA-256 для выбранного файла,
сравнивает контрольную сумму и проверяет `toudocu version` до замены. Ошибка
загрузки, проверки или подготовки временного файла не изменяет старый бинарник.
Если не удалось обновить `PATH`, уже проверенный бинарник остаётся установлен,
а пользователь получает предупреждение и инструкцию для ручной настройки.

Контрольная сумма защищает от случайного повреждения, но не является
независимой криптографической подписью: бинарник и сумма получены из одного
источника — GitHub Release.
Команды `curl | sh` и `irm | iex` также исполняют удалённый
установщик. Перед запуском его можно скачать отдельно и просмотреть.

Сеть и системные средства загрузки и вычисления хеша нужны только установщику.
После установки Toudocu остаётся одним автономным Go-бинарником без внешней
среды выполнения и сетевых загрузок во время обычной работы. Исключение —
необязательная проверка новой стабильной версии в основном режиме `serve`; её
можно отключить флагом `--no-update-check`.

## Собрать из исходников

Этот способ нужен для разработки Toudocu и проверки ещё не выпущенных
изменений:

```bash
git clone https://github.com/lumenikoly/toudocu.git
cd toudocu
make build
./toudocu version
```

Команда создаёт бинарник `toudocu` в корне рабочей копии. Она не добавляет его
в `PATH`: при необходимости переместите файл в собственный каталог программ.

Чтобы собрать текущий исходный код и обновить локальный бинарник одной
командой, выполните:

```bash
make update-local
```

По умолчанию цель устанавливает результат сборки в
`~/.local/bin/toudocu`. Другой каталог можно указать явно:

```bash
make update-local INSTALL_DIR="$HOME/bin"
```
