# Локальная работа с порталом

Команда `serve` подходит для повседневной работы: она собирает портал, запускает
локальный HTTP-сервер и добавляет редактор, просмотр изменений, обсуждения и
справку по внутреннему API.

## Полный рабочий путь

1. В корне проекта запустите:

   ```bash
   toudocu serve ./docs
   ```

2. Откройте напечатанный адрес. По умолчанию это
   `http://127.0.0.1:8080`.
3. Найдите документ через навигацию или поиск. На странице документа доступны
   действия «Редактировать», «Показать изменения» и «Открыть исходник».
4. В редакторе измените файл и сохраните его. Сервер проверит, что версия файла
   не успела измениться, запишет правку и перестроит модель, HTML и поиск.
5. Если файлы меняет внешний редактор или агент, дождитесь автоматического
   обновления. Несохранённый текст во встроенном редакторе не пропадает: при
   конфликте интерфейс просит выбрать дальнейшее действие.
6. Откройте «Изменения», чтобы проверить текущий Git diff. Обсуждение
   документации можно начать и продолжить там либо прямо на странице документа.
7. При необходимости на странице `roadmap.html` нажмите «Добавить результат»,
   выберите существующий этап, проверьте предложенный `DLV-ROADMAP-NNN` и
   введите одну строку результата.
8. После работы остановите сервер сочетанием `Ctrl+C`.

## Работа с агентом разработки

Agent Console доступна, когда `serve` открыт по локальному адресу, например
`http://127.0.0.1:8080`. Она работает с установленными Codex и OpenCode.

Чтобы выполнить готовую задачу:

1. Откройте раздел задач и выберите задачу, готовую к работе.
2. Нажмите значок Agent Console рядом с действием «Начать работу».
3. Если установлено несколько агентов, выберите нужного. До запуска также можно
   выбрать предложенную модель, глубину рассуждения и режим доступа.
4. Следите за ответом на вкладке Agent View. Вкладка Command Output показывает
   выполняемые команды и их результаты, но не принимает ввод.
5. При необходимости отправьте дополнительное указание. «Остановить ответ»
   прерывает только текущую работу, а «Остановить агента» завершает всю сессию.

Полный доступ расширяет права выбранного агента. Toudocu просит подтвердить его
отдельно для текущего проекта. Ограничения, заданные в настройках самого
агента, при этом сохраняются.

Панель открывается из заголовка на любой странице. Переходы между задачами,
документацией, изменениями и редактором не останавливают сессию. На широком
экране ширину панели и левой навигации можно менять перетаскиванием; выбранные
размеры сохраняются в браузере. На узком экране панель занимает доступную
ширину.

На странице задачи также доступны короткие действия: задать вопрос, уточнить
требования, продолжить работу или обновить документацию по текущим изменениям.
Они передают агенту нужный контекст автоматически. Действие «Обработать с
активным агентом» последовательно разбирает запросы, оставленные в обсуждениях.
Если агент уже занят другой задачей, новый запуск недоступен, но поручение всё
равно можно скопировать.

### Работа без Agent Console

У каждого действия задачи можно скопировать готовое поручение и передать его
любому внешнему агенту. Если автоматическое копирование не сработало, интерфейс
покажет текст для ручного копирования.

Терминал проекта открывается отдельной кнопкой и запускает обычную командную
строку в корне репозитория. В ней можно самостоятельно запустить `codex`,
`opencode`, `claude`, Git или другую программу. Терминал и Agent Console могут
работать одновременно; остановка одного не останавливает другой.

Ручная кнопка пересборки полезна, если нужно сразу перечитать документацию. Она
показывает, что именно перестраивается, и не перезагружает страницу до
завершения операции.

## Доступные адреса

- `/` — основной портал;
- `/_toudocu/editor/` — редактор разрешённых исходных файлов;
- `/changes/` — изменения Git и локальные обсуждения;
- `/_toudocu/api-docs/` — справка по HTTP API Editor, Changes и обратной связи
  с агентом;
- `/_toudocu/api/tasks/{taskID}/actions` — доступные действия задачи в основном
  `serve`, открытом по локальному адресу;
- `/_toudocu/locales/<locale>/` — портал выбранной локали.

Каждый портал локали содержит документацию, редактор, раздел «Изменения»,
обсуждения, ручную пересборку и рабочее пространство задач. Он записывает
изменения только в свой каталог. Agent Console и действия задачи доступны
только в основном `serve`. Если отдельной страницы нет, открывается главная
страница этой локали.

## Сеть и безопасность

По умолчанию сервер слушает только `127.0.0.1`, то есть доступен с текущего
компьютера. Флаг `--host 0.0.0.0` открывает его для локальной сети. В Toudocu
нет встроенных TLS и авторизации, поэтому такой режим нельзя выставлять в
недоверенную сеть; команда выводит об этом предупреждение.

Agent Console доступна только по локальному адресу. При любой другой привязке,
включая `--host 0.0.0.0`, она останется отключена независимо от настроек
пользователя.

Основной портал может проверить наличие новой стабильной версии. Это
единственный необязательный сетевой запрос самого Toudocu в этом режиме. Чтобы
его отключить, добавьте `--no-update-check`.

## Статическая публикация — другой режим

Отдельной команды `preview` нет. Для публикации выполните `toudocu build` и
разместите результат на [статическом HTTP-хостинге](deployment.md). В такой
сборке нет локального API, редактора, просмотра Git и записи в дорожную карту.
