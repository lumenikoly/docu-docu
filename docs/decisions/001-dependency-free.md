# ADR-001: Один автономный Go-бинарник

Toudocu поставляется одним Go-бинарником и не требует устанавливать зависимости
для запуска. Допустимые сторонние Go-модули описаны в
[ADR-003](ADR-003.md), [ADR-005](ADR-005.md) и [ADR-010](ADR-010.md): они компилируются внутрь бинарника
и не добавляют сетевой сервис или соседние файлы.

<!-- toudocu:section context -->
## Контекст

Утилита должна одинаково работать в локальном репозитории, CI и среде агента
без npm и отдельного Markdown-движка. При этом ей нужны безопасный HTML,
статический портал без сервера и локальный режим `serve`.

<!-- toudocu:section decision -->
## Решение

Основу составляет стандартная библиотека Go. Ресурсы встраиваются через
`go:embed`, а Markdown обрабатывает закрытый за собственной моделью Go-движок
из [ADR-005](ADR-005.md). Кроссплатформенный PTY из
[ADR-010](ADR-010.md) используется только явным локальным Project Terminal.

Библиотека для браузера допустима как закреплённый встроенный ресурс, если она
не требует сети или внешних файлов во время работы и для неё сохранены лицензия
и процесс обновления безопасности. Узкое исключение для запроса метаданных
стабильного релиза описано в [ADR-006](ADR-006.md): оно не загружает код и
отключается флагом.

Новая внешняя зависимость требует отдельного ADR с объяснением пользы, влияния
на поставку, безопасность и сопровождение.

## Причины

- Один воспроизводимый артефакт для каждой поддерживаемой платформы.
- Никакой установки пакетов и обязательной сети при обычной работе.
- Единый контроль экранирования и локальных ссылок.
- Простое размещение в существующем проекте и CI.

<!-- toudocu:section consequences -->
## Последствия

Поставка и запуск остаются простыми, кросс-компиляция — прямой, а встроенные
ресурсы не теряются. Mermaid работает без Node.js и CDN; портал открывается
через HTTP-хостинг или `serve`.

Цена решения — ответственность команды за политику Markdown, безопасную
отрисовку, обновление Goldmark и встроенных браузерных библиотек. Такие
обновления требуют проверки совместимости, лицензий и известных уязвимостей.

## Статус пересмотра

Решение нужно пересмотреть, если встроенные Go-зависимости перестанут сохранять
автономную поставку или стоимость их сопровождения станет выше пользы.
