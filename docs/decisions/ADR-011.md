# ADR-011: Действие задачи не определяет способ доставки

Смысл действия над задачей принадлежит прикладному слою, а Agent Console и
handoff остаются альтернативными способами доставки готовой инструкции.

<!-- toudocu:section context -->
## Контекст

Раньше доступность действий зависела от Agent Console, а обработчики HTTP
отдельно запускали поставщика, формировали инструкцию и меняли Markdown задачи.
Поэтому одно действие нельзя было безопасно передать внешнему агенту, а активная
сессия могла принять действие другой задачи.

<!-- toudocu:section decision -->
## Решение

Один закрытый реестр задаёт идентификатор, допустимые состояния, ввод, политику
ответа, изменение состояния задачи и функцию подготовки инструкции. Сервер
перечитывает модель при построении проекции и непосредственно перед выполнением.
Способ доставки выбирается отдельно из закрытого набора
`agent-console | handoff` и не входит в идентификатор действия.

Markdown задачи остаётся источником долговременного состояния. Agent Session
хранит связь с задачей, но не копию её контракта. Handoff возвращает инструкцию
и не запускает внешний процесс.

<!-- toudocu:section consequences -->
## Последствия

- браузер получает безопасную для показа проекцию без шаблонов инструкций;
- `start-work` применяет один переход `ready → in-progress` для обоих способов
  доставки;
- Agent Console отклоняет доставку в сессию другой задачи;
- переносимый handoff доступен без установленного поставщика со структурированным
  протоколом;
- новые способы доставки не требуют новых идентификаторов действий, но требуют отдельного
  архитектурного решения, если меняют границу доверия.
