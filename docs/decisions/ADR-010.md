# ADR-010: Кроссплатформенный PTY для Terminal Mode

Terminal Mode использует `github.com/aymanbagabas/go-pty` версии `v0.2.2` и
встроенный browser terminal `@xterm/xterm` версии `6.0.0`.

<!-- toudocu:section context -->
## Контекст

Настоящий интерактивный fallback требует Unix PTY и Windows ConPTY. Стандартная
библиотека Go не предоставляет единого API, а самостоятельная реализация
ConPTY потребовала бы небезопасного платформенного кода и дублировала бы
существующий проверяемый модуль. Актуальная ветка `go-pty` требует Go 1.25,
тогда как Toudocu поддерживает Go 1.22.

<!-- toudocu:section decision -->
## Решение

Закрепить последнюю совместимую с Go 1.22 версию `go-pty` — `v0.2.2`. Она
компилируется внутрь автономного бинарника без CGO и использует Unix PTY либо
Windows ConPTY. Её MIT-лицензия и лицензии транзитивных модулей сохранены в
`THIRD_PARTY_NOTICES.md`.

Закрепить `@xterm/xterm@6.0.0` и `@xterm/addon-fit@0.11.0`. Они собираются в
отдельные dynamic JS/CSS chunks, входят только в `serve` asset closure и
загружаются browser только после доступности Terminal Mode.

<!-- toudocu:section consequences -->
## Последствия

- поставка остаётся одним бинарником и не требует сети во время работы;
- обновление `go-pty` требует проверки минимальной версии Go, ConPTY/Unix PTY,
  лицензий и advisories;
- browser не передаёт executable или argv: trusted provider формирует `codex`
  и добавляет только семантический `--yolo` для `Full access`;
- собственная реализация PTY не поддерживается внутри Toudocu.
