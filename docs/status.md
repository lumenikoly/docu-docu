# Текущее состояние

Текущая стабильная версия — `0.0.6`. Установщики GitHub Release для POSIX и
PowerShell выбирают подходящий бинарник и проверяют контрольную сумму перед
заменой программы.

<!-- toudocu:section summary -->
## Краткое состояние

CLI проверяет, собирает и локально раздаёт документацию, формирует
типизированные JSON-отчёты, выдаёт контекст выбранной задачи и выполняет её
проверки только по явной команде. Корневой Go-пакет предоставляет стабильный
фасад модели, генерации и отчётов для локального встраивания из исходного
дерева; CLI остаётся публичным интерфейсом поставки. Встроенная Mermaid Tiny
отображает связанные процессы без CDN или Node.js. Безопасность путей, HTML,
диаграмм, HTTP-раздачи и ограничения времени выполнения покрыта тестами
запрещённых сценариев.

Модель процессов формирует раздельные каталоги `UC-*` и `FLOW-*`, стабильные
URL по ID и страницу пользовательского сценария с описанием, картой,
пошаговым прохождением и связями. Экранная модель формирует каталог, общую карту
с SVG-связями, структуру вложенности, интерактивные области и таблицу связей.
Статический портал работает через HTTP(S), поддерживает клавиатуру, сенсорное
управление и понятные состояния ошибок; для
локального просмотра используется `serve`.

Активные задачи, блокеры и следующий результат вычисляются из рабочих задач и
дорожной карты и отображаются в HTML автоматически. В локальном разделе
«Изменения» реализованы просмотр файлов всего репозитория, фильтр по виду файла,
полный текст файла и те же обсуждения документации, что в Портале. Сообщение
не требует отдельной отправки: сохранение сразу создаёт запись очереди, которую
можно изменить или удалить до получения агентом. Интерфейс не запускает агента сам.

## Готовность

Исходный код и встроенные ресурсы поставляются одним бинарником без внешней
среды выполнения. Закреплённые Go-зависимости Goldmark и OpenAPI YAML
включаются в бинарник. Форматирование, обычные тесты, поиск гонок данных,
`go vet`, проверка модулей, строгая проверка обоих каталогов документации и
сборка для шести целевых платформ входят в команды `make check` и
`make release`. Релизный комплект
включает два установщика; они выбирают подходящий бинарник и проверяют его
SHA-256 до замены файла в пользовательском каталоге программ.
